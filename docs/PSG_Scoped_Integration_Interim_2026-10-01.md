# Scoped PSG integration: interim repository anchor

This is a synchronized work-in-progress checkpoint, not completed transport
acceptance. The governing contract and eventual receiving gates are in the
[integration checkpoint](PSG_Transport_Integration_Auditor_Checkpoint_2026-10-01.md).

## Implemented boundary

BAREWire supplies bounded byte-source readings. Fidelity.PSG Schema 15 adds
source-owned entries, complete occurrence contexts, compact stamped positional
accounts, typed binding-use facts and current claims. The scope/delta contract
separates installed content from current source authorization. Complete revision
images remain local inspection artifacts; they are not a service operation.

Baker computes demanded live bodies and selected settled facts, retaining full
conservative owner support internally. It freezes PSG leaf tables during source
preparation. The single publication exit copies those stored tables. Neither an
unused `open` nor inactive declaration membership authorizes body transmission.
Alex's new readers consume binding, representation, symbol and pool facts without
loading inactive participants. The source pool contract requires current matching
proof incidence, not merely a retained proof body.

Bozzetto source uses shared socket control contracts; the prohibited complete
graph operation and its special capacity path are absent. Public MCP/browser
JSON adapters remain separate from private service transport.

## Remaining integration

1. Finish passive Alex entry/traversal, selective-region and Composer artifact
   path migration; existing consumers still contain old path assumptions.
2. Replace PSG's body-census integrity rule with typed reference validation:
   bodies, boundary facts, current claims, context accounts and historical support
   are distinct roles. A union of all identities is insufficient.
3. Update native mapper generation policy for the new scoped types and manual
   source-reading helpers. Do not regenerate native mappings with the old policy.
4. Carry complete demanded fact scopes over socket subscriptions, with exact-base
   atomic install, reservation fences, acknowledgements and joined retirement.
5. Exercise the actual receiving packet through proof, passive witnessing and
   native compilation, including unchanged reuse and newly demanded dependencies.

No receiver may reconstruct missing source facts, infer reachability, or request
a whole retained graph to compensate for these unfinished boundaries. Errors
must identify the missing owning contract.
