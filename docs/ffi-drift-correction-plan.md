Classify every disputed predicate before editing it:

| Predicate class | Proper authority and required disposition |
| --- | --- |
| Source semantic decision or relationship | Existing Baker elaboration/saturation owner settles it; publish its result and remove downstream reconstruction. |
| Published structural invariant | PSG integrity admits or refuses the shape; retain its single contract authority. |

| Actual artifact/correspondence validation | Composer inspects actual realization against independently bound facts; preserve this check while removing source reconstruction. |
| Supported-profile limitation | State its bounded scope and retain the refusal until the expanded shape has correspondence evidence. |

Fresh-name generation is not automatically source SSA assignment; a declared discriminator or platform constant is not automatically semantic reconstruction. Conversely, a refusal-only check can still be a second source or contract authority. Each classification needs its actual predicate and counterexample, not its function name.
